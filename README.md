# record-collection

A catalogue of records owned and wanted.

- **[HOWTO.md](HOWTO.md)** — running it locally, and which of the three
  databases you are actually writing to. Read this before entering real
  records: `npm run dev` defaults to the *test* database, which the suite wipes.
- **[SPEC.md](SPEC.md)** — the feature specification. Authoritative.
- **[CLAUDE.md](CLAUDE.md)** — how work is done in this repository.
- **[NOTES.md](NOTES.md)** — running observations, corrections and open items.
  Start with the CURRENT POSITION block.

SPEC.md §14 asks the README to cover setup, migrations, the Discogs token, the
test suites and deploying. HOWTO.md covers the first two and the suites;
Discogs is step 7 and deployment is step 14, so those sections arrive with them.
