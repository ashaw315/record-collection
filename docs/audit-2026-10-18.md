### 1. The Neon test's "UNVERIFIED" entry is skipped on every run, whatever the branch's state. Fix, don't delete.

- **Where:** `test/integration/neon-transactions.test.ts:302` and `:133-136`.
- **Evidence (rechecked):**
  - `it.skipIf(!remote || skipRemote === null)` is evaluated when Vitest collects the file. `skipRemote` is `null` until `beforeAll` assigns it (line 254), and `beforeAll` runs after collection. So the test is skipped on every run.
  - Its name, "UNVERIFIED against a real Neon branch: its credential expired", is printed in the skipped list on every run: with no branch, with a healthy branch, and with an expired one alike.
  - The comment above it says the entry appears "only when a configured branch could not be reached". The code doesn't do that.
  - This is CLAUDE.md §2's absent / broken / working defect in the one file written to prevent it: an expired credential and a healthy branch now read the same.
  - Also, at `:133-136`, "names the target the driver is verified against" compares an expression with itself and checks `const configured = true`. Its name overstates what it checks.
- **Risk:** needs a look. This is shared test infrastructure, so it's a gate change.
- **Effort:** small.
