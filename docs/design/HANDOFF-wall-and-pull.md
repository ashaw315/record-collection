# Handoff — the wall and the pull (§W), and the record detail (§12–§31)

**This file is a pointer index, not an excerpt.** It says which subsection of the build target governs what. It does **not** restate the rules — the previous version of this file was a full excerpt and went stale twice: it carried §W.1's withdrawn "width is what the eye can use before reading" claim after that claim was reversed, and it predated §W.5, §W.6 and §W.7 entirely. **Same conclusion as the §9 handoff: the pointers never went stale, every restatement did.**

**Two sources of truth.** `§W` and `§W.N` rows point into **`Wall and Pull - build target.dc.html`**. All other rows (§1–§10, §12–§31) point into **`Record Detail 8a - build target.dc.html`**. If this file and a target disagree, the target is right and this file is the defect. **A row can omit a clause without contradicting its section, so a claim that a section does NOT say something must be checked against the section itself.**

**Renumbering.** The wall was §11 of the record-detail target, and its subsections were §11.1–§11.37. They are moved unchanged and renumbered **§11.N → §W.N**. No other number changed. **§27 is the eyebrow ruling (§27 · The eyebrow returns to the flow).** The hairline value is **§W.27** (was §11.27). A build that took §27 to mean the hairline was reading §11.27 with the 11 dropped, and that is the collision the renumbering removes.

**Reachability.** Every target this index names must be reachable wherever the index is read, and at the same revision as the index. That now means two files. An index naming a source its reader cannot open is the stale-excerpt defect again. How the files are made reachable is not this file's decision.

**This supersedes `HANDOFF-wall-colour.md`.** That export ruled spines take the raw sampled value and withdrew the record screen's clamp to match. Both are reversed. Delete it.

## The one-line premise

The wall at rest is line, ink and paper; colour arrives with the pull. Everything below is where that is worked out.

## Maintaining this file

**Every numbered section in either target must have a row above.** This index has failed three times, differently each time: first as an excerpt that went stale, then by deferring to a section the repo's copy did not contain, then as a pointer index missing a pointer. 1. **Every heading has exactly one row.** Grep both targets for every numbered heading, with or without a leading `§` (`N ·`, `N.M ·`, `§N.M ·`, `W ·`, `W.N ·`), and assert each appears in the two tables exactly once, counting a row by its section label whatever follows it.
